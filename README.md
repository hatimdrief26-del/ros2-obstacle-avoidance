# 🤖 Obstacle-Avoiding Robot with ROS2

## 📌 Overview
This academic project focuses on the simulation of a mobile robot capable of detecting and avoiding obstacles using ROS2.

## 🛠️ Technologies
- ROS2
- Gazebo
- RViz
- Ubuntu Linux

## 🎯 Objectives
- Develop a mobile robot using ROS2.
- Simulate the robot in Gazebo.
- Visualize the robot using RViz.
- Implement obstacle detection and avoidance.
